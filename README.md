 AI Music Generator

An AI-based music generation web application developed using Flask and LSTM neural networks.
The project learns musical patterns from MIDI datasets and generates new note sequences capable of producing original melodies.

This project was built to explore the practical application of deep learning in creative domains such as music composition, sequence prediction, and pattern generation.

 Overview

The system processes MIDI files, extracts musical note sequences, and trains an LSTM model to understand temporal relationships between notes.
After training, the model predicts subsequent notes based on learned musical structures and generates new music sequences.

The generated output demonstrates how recurrent neural networks can be applied to sequential data beyond traditional text-based tasks.

Features

* MIDI file preprocessing and note extraction
* Sequence creation for neural network training
* LSTM-based music pattern learning
* AI-generated melody prediction
* Flask web application for interaction
* Dynamic music generation workflow
